# Code of Conduct

We're building a useful tool, not a comment-section endurance test. Be respectful and help keep project discussions welcoming.

## Expected behavior

- Be kind, patient, and constructive.
- Critique ideas and code, not people.
- Explain disagreements without insults or harassment.
- Respect privacy. Don't publish someone else's personal information.
- Assume good faith while staying open to correcting mistakes.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, deliberate intimidation, and sustained personal attacks are not welcome.

## Handling issues

If something goes wrong, contact the project maintainer privately through the GitHub profile or repository reporting tools. Please avoid posting sensitive personal information in public issues.

Maintainers may edit, remove, or close content that violates this code. This document is intended to keep the project usable and respectful, not to police ordinary technical disagreement.
