# Requirements

## Must Have

- Windows support
- macOS support
- Global hotkey
- Floating assistant interface
- Voice input
- Text input
- Configurable AI provider
- AI agent loop
- Tool system
- Browser control
- Keyboard control
- Mouse control
- Screen observation
- Persistent memory
- Settings
- Error handling
- Permission handling

## Should Have

- Streaming responses
- Tool execution visualization
- Search
- Text-to-speech
- Application launching
- File operations
- Terminal operations
- Confirmation before sensitive actions
- Action history

## Nice To Have

- Multiple agent profiles
- Custom tools
- Plugins
- Advanced computer vision
- Scheduled tasks
- Background agents
- Cross-device synchronization

## Constraints

The application must remain responsive while AI operations are running.

Long-running operations must not freeze the UI.

All external operations should have clear failure handling.
