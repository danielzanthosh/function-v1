# Function Typography

## Philosophy

Typography should feel technical, precise, and calm.

It should support dense information without feeling like a developer console.

## Primary Typeface

Use a modern system UI sans-serif.

Prefer platform-native system typography where practical.

Windows:
Segoe UI / appropriate system UI font

macOS:
SF Pro / appropriate system UI font

The application should maintain consistent hierarchy across platforms.

## Monospace

Use a high-quality monospace font for:

- Tool names
- Keyboard shortcuts
- Commands
- URLs
- Technical values
- Logs
- Code

## Hierarchy

### Display

Used rarely.

For major application states or onboarding.

### Heading

Used for:

- Window titles
- Sections
- Settings categories

### Body

Primary readable interface text.

### Secondary

Supporting information.

### Metadata

Small contextual information.

### Monospace

Technical information.

## Typography Principles

Prefer fewer sizes.

Use weight and spacing to create hierarchy.

Do not make every section a different font size.

Avoid excessive bold text.

Do not use uppercase text everywhere.

## Numbers

Important numerical results should use clear alignment.

Analytics and structured values should prioritize readability.

## Accessibility

Text must remain readable at normal system scaling.

The interface must support platform text scaling where practical.
