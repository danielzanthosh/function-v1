# Vision

Build a native AI computer assistant that can understand natural-language instructions and operate Windows and macOS computers on the user's behalf.

The long-term goal is a general-purpose computer-use assistant.

The first version should focus on proving the core interaction:

User intent
→ AI reasoning
→ tool execution
→ observation
→ completion

The product should demonstrate that an AI can meaningfully operate a real desktop environment.

The assistant should not simply answer questions.

It should be capable of taking actions.
