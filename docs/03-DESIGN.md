# Design System

## General

The UI should prioritize clarity and speed.

Every visual element should have a purpose.

## Principles

1. Reduce visual noise.
2. Make important information obvious.
3. Prefer hierarchy over decoration.
4. Use animation only when it communicates state.
5. Keep interactions predictable.
6. Preserve platform conventions.
7. Make keyboard interaction first-class.

## Typography

Use a highly readable modern UI font.

Typography should have clear hierarchy:

- Application title
- Section title
- Primary content
- Secondary information
- Metadata
- Tool status
- Error state

Avoid excessive font weights.

## Spacing

Use a consistent spacing scale.

Do not manually invent random spacing values throughout the application.

## Surfaces

Use a small number of surface levels:

- Base
- Elevated
- Floating
- Active

Avoid excessive nested cards.

## Color

The interface should support light and dark themes.

Color should communicate:

- State
- Importance
- Success
- Warning
- Error
- Activity

Do not use color purely for decoration.

## Animation

Animations should be short and purposeful.

Examples:

- Assistant appearing
- Listening state
- Tool execution
- Completion
- Error

Avoid constant motion.

## Interaction

Every interactive component must provide clear hover, focus, pressed, and disabled states where appropriate.
