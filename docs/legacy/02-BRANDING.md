# Function Brand

## Brand Name

Function

The product name is simply:

Function

Do not append "AI", "Assistant", "Desktop", or similar descriptors to the primary brand name.

Examples:

Function
Function Settings
Function Memory
Function Tools

## Brand Concept

Function is a native desktop computer assistant.

The name represents the product's core purpose:

A function receives intent and produces an action.

The assistant takes a user's intent and turns it into actions performed on the computer.

The brand should therefore feel:

- Technical
- Precise
- Intelligent
- Minimal
- Fast
- Native
- Powerful
- Controlled

## Brand Personality

Function is quiet and confident.

It does not need to look futuristic to communicate advanced technology.

It should feel like software made by people who care about computing.

The visual language should be closer to:

- Zed
- Raycast
- Linear
- Native operating-system utilities
- Professional developer tools

rather than:

- Generic AI chatbots
- Sci-fi dashboards
- Gaming interfaces
- Consumer AI mascots

## Core Visual Idea

The primary visual language is based on the Function icon:

A geometric white form emerging from darkness.

The central point represents:

- Focus
- Execution
- Direction
- Convergence
- Intent becoming action

The surrounding vertical form represents:

- Structure
- Computing
- Context
- A controlled environment

The sharp lower opening creates visual tension and gives the symbol a distinctive silhouette.

## Brand Principle

Function should look powerful without trying to look powerful.

Minimalism is not the absence of design.

It is deliberate reduction.

## Do Not Use

Avoid:

- Robot imagery
- Brain imagery
- Circuit-board clichés
- Neon cyberpunk styling
- Excessive purple
- Excessive blue
- Rainbow gradients
- Glassmorphism as the primary visual language
- Floating blobs
- Generic sparkle icons
- Cartoon mascots
- Excessive rounded containers
- Decorative futuristic HUD elements

## Primary Brand Statement

Function turns intent into action.

## Short Description

A native AI computer assistant for Windows and macOS.
