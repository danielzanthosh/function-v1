# UX Flows

## Open Assistant

User presses:

macOS:
Double Command (⌘ ⌘)

Windows:
Ctrl + Space

↓

Assistant appears.

## Voice Request

User holds or activates voice input.

↓

Listening indicator.

↓

User speaks.

↓

Speech recognition.

↓

Request appears.

↓

Agent begins.

## Agent Task

Request
↓
Planning
↓
Tool execution
↓
Observation
↓
More actions
↓
Completion

## Completion

The assistant presents the result.

The user can:

- Continue
- Copy
- View activity
- Close

## Error

Show:

What happened
Why it failed when known
What action was attempted

Avoid exposing technical internals unless useful.
