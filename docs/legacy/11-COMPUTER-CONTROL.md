# Computer Control

The assistant must be capable of interacting with the computer.

## Mouse

Support:

- Move
- Click
- Double click
- Right click
- Scroll
- Drag

## Keyboard

Support:

- Key press
- Text typing
- Keyboard shortcuts

Typing may optionally be visually animated for demonstrations, while execution remains efficient.

## Screen

Support:

- Screenshot
- Region capture
- Screen dimensions
- Multi-monitor awareness

## Applications

Support:

- Launch
- Focus
- Minimize
- Close

## Safety

Do not allow arbitrary uncontrolled input injection.

Computer actions must be initiated through the agent tool system.

## Observation

After significant actions, the agent should be able to observe the resulting state.
