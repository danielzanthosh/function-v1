# Function Icon

## Source

The Function icon is a monochrome geometric symbol on a black background.

The current reference icon should be treated as the canonical starting point for the visual identity.

## Visual Characteristics

The icon contains:

- A black background
- A vertical gray-to-white structure
- A bright central convergence point
- Two diagonal edges forming an open lower section
- Strong vertical symmetry
- High contrast
- No text
- No decorative elements

## Meaning

The symbol should communicate:

Intent
↓
Focus
↓
Execution

The central convergence point is the key visual element.

It can represent the moment where the assistant understands what the user wants and begins execution.

## Geometry

The symbol should remain geometrically simple.

Important characteristics:

- Vertical axis
- Strong symmetry
- Sharp central point
- Large negative space
- Simple silhouette

Do not add unnecessary internal details.

## Color

Primary icon:

Black background
White/gray symbol

The icon should work in pure monochrome.

## Variants

Required variants:

1. Primary dark icon
2. Light-background icon
3. Monochrome white icon
4. Monochrome black icon
5. Small-size simplified icon

## Small Sizes

At small sizes, preserve the silhouette rather than tiny gradients.

The icon must remain recognizable at:

- 16px
- 20px
- 24px
- 32px
- 48px
- 64px
- 128px
- 256px
- 512px
- 1024px

## App Icon

The desktop application icon should use the symbol without text.

Do not place "Function" inside the application icon.

## Clear Space

Maintain a clear area around the symbol.

Do not place text or other symbols directly against the icon.

## Incorrect Usage

Do not:

- Rotate the icon
- Stretch the icon
- Compress the icon
- Add drop shadows
- Add outlines
- Add random gradients
- Add glow effects
- Add text inside the symbol
- Change the central geometry

## Motion

The icon may be animated subtly in application states.

The base geometry must remain recognizable.
