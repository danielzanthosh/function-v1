# Function Color System

## Philosophy

Function uses a restrained monochrome-first palette.

Color should communicate state rather than decorate the interface.

The icon establishes the primary visual language:

Black
White
Gray

Accent colors are secondary.

## Core Palette

### Void

#000000

Primary deepest background.

Use for:

- Application background
- Icon background
- Full-screen surfaces

### Carbon

#0A0A0A

Near-black surface.

Use for:

- Main panels
- Floating windows
- Secondary surfaces

### Graphite

#141414

Raised surface.

Use for:

- Inputs
- Tool rows
- Secondary containers

### Ash

#2A2A2A

Borders and subtle separators.

### Smoke

#666666

Secondary text.

### Silver

#A3A3A3

Metadata and inactive UI.

### White

#FFFFFF

Primary text and important UI.

## Accent

Function should use white as its primary active accent.

The brand does not require a permanent colored accent.

## Semantic Colors

Color should be introduced primarily for semantic states.

Success:
#4ADE80

Warning:
#FACC15

Error:
#F87171

Information:
#60A5FA

These colors should remain restrained.

They should not dominate the interface.

## Gradient

The icon's grayscale transition may be used selectively.

Do not turn the entire application into a gradient-based interface.

Gradients are primarily appropriate for:

- Icon
- Assistant activity indicator
- Extremely subtle state effects

## Light Theme

The light theme should invert the hierarchy rather than simply using pure white everywhere.

Primary background:
#F7F7F5

Primary surface:
#FFFFFF

Secondary surface:
#F0F0EE

Primary text:
#111111

Secondary text:
#666666

Border:
#D8D8D5

## Dark Theme

Dark theme is the primary visual environment.

Primary background:
#000000

Primary surface:
#0A0A0A

Secondary surface:
#141414

Primary text:
#FFFFFF

Secondary text:
#A3A3A3

Border:
#2A2A2A

## Color Rules

Do not use color to make every component interesting.

Most of the UI should remain neutral.

Use semantic colors only when they provide information.

A user should be able to understand the interface without relying entirely on color.
