Implement native computer control.

Required capabilities:

Mouse:
- Move
- Click
- Double click
- Right click
- Scroll
- Drag

Keyboard:
- Key press
- Text typing
- Shortcuts

Screen:
- Screenshot
- Region capture
- Screen dimensions

Application:
- Launch
- Focus
- Close

Create platform abstractions.

Implement Windows and macOS separately where required.

Do not bypass operating-system permissions.

Test each operation independently.
