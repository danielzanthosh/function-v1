- docs/14-AI-PROVIDERS.md

Build the settings interface.

Settings should include:

AI:

- Base URL
- API key
- Model

Voice:

- Speech provider
- Voice settings

Search:

- Provider configuration

Application:

- Hotkeys
- Theme
- Startup behavior

Memory:

- Memory controls

Store secrets using platform-secure credential storage.

Never display stored secrets unnecessarily.

Keep the settings interface simple and native.
