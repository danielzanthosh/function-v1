# Browser Control

Read:

- docs/12-BROWSER.md
- docs/10-TOOLS.md

Implement browser automation.

Initial browser targets:

- Chrome
- Edge

Use Playwright where appropriate.

Support:

- Launch/open
- Navigate
- Click
- Type
- Read
- Screenshot
- Extract structured content

The browser tool must return structured results.

Do not expose credentials.

Do not automatically perform consequential actions without confirmation.

Implement recovery when pages change or selectors fail.
