# GPUI Shell

Read:

- PRODUCT.md
- docs/03-DESIGN.md
- docs/04-LAYOUT.md
- docs/18-GPUI.md

Build the initial GPUI application shell.

Implement:

- Main application window
- Floating assistant window
- Basic layout
- Theme system
- Input field
- Assistant state display
- Keyboard actions

The design should feel like a serious native developer tool.

Use Zed as an architectural and interaction-quality reference, not as something to copy.

Avoid:

- Glassmorphism
- Huge rounded cards
- Generic chatbot UI
- Excessive gradients
- Decorative AI imagery

The UI must remain functional and extensible.

Do not implement the AI agent yet.

Verify compilation after implementation.
