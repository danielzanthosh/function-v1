# Build and Release

Read:

- docs/23-BUILD.md
- docs/22-TESTING.md
- docs/17-PLATFORM.md

Prepare the application for release.

Verify:

- Clean build
- Tests
- Windows build
- macOS build
- Configuration
- Permissions
- Global hotkey
- AI provider
- Voice
- Browser
- Computer control
- Memory
- Settings

Ensure:

- No secrets are included
- Debug logging is removed or appropriately controlled
- Errors are handled
- Application packaging works

Document the build and release process.

Do not claim a platform works unless it has actually been tested.
