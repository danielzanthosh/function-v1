# Polish

Read all documentation before modifying the UI.

Perform a complete UX and visual polish pass.

Focus on:

- Spacing
- Typography
- Hierarchy
- Animation
- Interaction feedback
- Keyboard navigation
- Loading states
- Empty states
- Error states
- Accessibility
- Dark/light themes
- Windows behavior
- macOS behavior

Remove:

- Unnecessary UI
- Repeated information
- Decorative elements
- Generic AI styling
- Visual clutter

The final application should feel like a serious native desktop product.

Do not redesign working architecture merely for aesthetics.
