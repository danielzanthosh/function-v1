# Memory

Read:

- docs/09-MEMORY.md
- docs/19-DATA.md

Implement persistent memory.

Use SQLite.

Support:

- Create memory
- Retrieve memory
- Update memory
- Delete memory
- Search/retrieve relevant memories

Memory should be relevance-based.

Do not inject the entire memory database into every AI request.

Create clean interfaces so the retrieval system can later use embeddings.

The user must be able to control stored memory.

Do not store secrets as ordinary memory.
