# Branding

Read:

- PRODUCT.md
- docs/02-BRANDING.md
- docs/03-DESIGN.md

Establish the product's visual identity.

Create:

- Application identity
- Icon direction
- Typography system
- Color tokens
- Theme tokens
- UI naming conventions

Do not over-design the product.

The identity should feel intelligent, technical, precise, and modern.

Avoid generic AI visual language.

Do not introduce unnecessary illustrations or gradients.

Keep the branding usable on both Windows and macOS.
