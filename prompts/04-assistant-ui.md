# Assistant UI

Read:

- PRODUCT.md
- docs/03-DESIGN.md
- docs/04-LAYOUT.md
- docs/20-UX-FLOWS.md

Implement the main assistant interface.

Required states:

- Idle
- Listening
- Processing
- Acting
- Confirmation
- Completed
- Error

Implement:

- Compact floating assistant
- Expanded workspace
- Input
- Status indicator
- Activity display
- Result display

The UI must communicate state without exposing private AI reasoning.

Use concise action descriptions.

Example:

Opening Chrome
Navigating to YouTube Studio
Reading analytics

Do not build a generic chat application.

Make the assistant feel like a desktop command center.
