# Security

Read:

- docs/16-SECURITY.md
- docs/10-TOOLS.md
- docs/11-COMPUTER-CONTROL.md

Perform a security pass.

Inspect:

- API key handling
- Tool permissions
- Terminal execution
- File deletion
- Browser automation
- Memory
- Logs
- IPC
- Configuration

Ensure sensitive actions require confirmation.

Ensure secrets are never logged.

Ensure arbitrary tool execution cannot bypass permission checks.

Do not add unnecessary security complexity.

Prioritize practical protections around actual privileged operations.
